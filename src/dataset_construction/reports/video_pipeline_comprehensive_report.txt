3. ST-GCN (P4) ARCHITECTURE & TRAINING TAXONOMY (final_dataset_v2)
================================================================================

3.1 Network (video/pose-models/models/p4_pose_stgcn.py, models/blocks.py)
    - Input: (T,V,C) with T=35, V=17, C=3 (x, y, confidence) after normalization.
    - Encoder: STGCN_Encoder — three STGCNBlock stages, channel schedule
      dims→32→64→64 (dims=3 default).
    - Graph: fixed 17-joint feline adjacency _cat_adjacency; normalized A.
    - Each STGCNBlock: spatial graph conv with A, BatchNorm2d, temporal Conv2d
      kernel (3,1) same padding, residual.
    - Pooling: mean over time, mean over joints → 64-D embedding.
    - Heads: MLPBlock(64→128→K) → logits_5 (historic name; K=5, 10, or 2);
      MLPBlock(64→128→2) → logits_binary (pain vs non-pain).

3.2 Loss / objectives (video/pose-models/training_loop.py)
    - binary_only false: focal loss on logits_5 (K-way) AND logits_binary vs
      binary_label_int; macro-F1 + top-3 (K≥3) + binary metrics.
    - binary_only true (pairwise): binary focal; early_stop_metric typically
      val_macro_f1_binary; n_classes=2 for head width.

3.3 Track summary table
    ---------------------------------------------------------------------------
    Track | Label field      | K / role          | binary_only | Dual heads | #models
    ---------------------------------------------------------------------------
    A     | audio_label_10   | 10-class general  | false       | yes        | 1 shared
    B     | final_label_5    | 5 merged classes| false       | yes        | 1 shared
    C     | audio_label_10   | OvO per pair      | true        | binary only| 45 pairwise
    ---------------------------------------------------------------------------

    Track A — config: video/pose-models/config_p4_10class.yaml
              Classes: Angry, Defence, Fighting, Happy, HuntingMind, Mating,
              MotherCall, Paining, Resting, Warning (audio_label_10).
              Early stop: val_macro_f1 on 10-way head.

    Track B — config: video/pose-models/config.yaml (pose-models)
              Classes: final_label_5 + binary_pain_class Paining.

    Track C — script: video/pose-models/run_p4_pairwise.py
              config: video/pose-models/config_p4_pairwise.yaml
              C(10,2)=45 unordered pairs.
              Pain-inclusive pairs: 9 (Paining vs each other class).
              Non-pain-only pairs: C(9,2)=36 among non-Paining classes.
              Check: 9 + 36 = 45.
              pair_binary_neg_pos (class_subset_utils.py): if Paining in pair,
              it is positive class (1); else lexicographic order for 0/1.

3.4 Stacking feature sets (train_stgcn_dlc_stack.py)

4.2 LLM FGS protocol (video/gpt-fgs/cat_pain_llm_eval.ipynb)
    The notebook instructs the model to score **five** FGS-style action units per **frame**,
    each on a 0–2 scale, using JSON keys **ear_position**, **orbital_tightening**,
    **muzzle_tension**, **whiskers_change**, **head_position** (the user-facing text in
    the prompt uses the corresponding plain-language labels: ear position, orbital
    tightening, muzzle tension, whiskers change, head position).
    **Consensus across frames:** for each AU, the clip-level value is the **maximum**
    across frames. **fgs_total** is the **sum** of those five consensus AU scores (maximum
    10). **pain_binary** is **Pain** if **fgs_total >= 4**, otherwise **No_Pain**
    (see consensus / evaluation cells; also used when deriving pain from **fgs_total**
    columns in analysis).
    The fixed comparison rows **GPT-4o FGS (corrected)** (macro F1 **0.353**, sens. **0.702**,
    spec. **0.332**) / **label-derived** in video/cnn-finetuning/src/evaluate.py are
    **hard-coded constants** in the GPT-4o rows of `evaluate.py` (see `write_final_report`) — not produced by the CNN training
    pipeline. They are **not** computed on **final_dataset_v2** unless someone re-runs LLM
    evaluation and overwrites these literals.
    **Notebook cohort (confirmed):** `cat_pain_llm_eval.ipynb` sets
    `MANIFEST_PATH = "dataset/final_dataset.jsonl"` (legacy). Unless that cell is changed,
    FGS metrics computed in the notebook are **not** on the same manifest as
    `src/dataset_construction/manifests/final_dataset_v2.jsonl`. Treat CNN (v2) vs LLM
    (FGS) rows as **different cohorts** in write-ups unless you re-evaluate FGS on v2.

5. META-LEARNER (STACKING) — APPROACHES, EXPERIMENTS, BEST NUMBERS ON DISK
================================================================================

5.1 Primary script
    video/pose-models/scripts/train_stgcn_dlc_stack.py
    Features: one probability per pairwise base model (softmax positive class for
    OvO binary heads). build_run_specs() sweeps:

    - LogisticRegression L1 (saga): C ∈ {0.001, 0.01, 0.1, 1, 10, 100}
    - LogisticRegression L2 (lbfgs): same C; class_weight balanced; max_iter 2000
    - ElasticNet (SGD-style grid): alpha ∈ {1e-4,1e-3,1e-2} × l1_ratio {0.15,0.5,0.85}
    - RandomForestClassifier: 5 configs (n_estimators / max_depth)
    - XGBClassifier: 7 combos; hist tree; binary or multiclass objective
    - LGBMClassifier: 5 configs
    - MLPClassifier: hidden in {(64),(128),(256),(128,64),(256,128),(64,32),
      (128,64,32),(256,128,64)} × alpha {1e-4,1e-3,1e-2}
    - SVC RBF: C ∈ {0.1,1,10,100} × gamma {scale, auto}
    - KNeighborsClassifier: k ∈ {3,5,9,15} × weights {uniform, distance}
    - GaussianNB: single run

    CLI: --holdout-manifest, --model-dirs-json (45 dirs), --pain-pair-models-only,
    --meta-binary-pain, --min-best-epoch, --audio-confidence-filter, --cv-splits,
    --split-fraction, --random-seed

7.1 Pose body-region ablation
    Script: video/pose-models/scripts/p4_pose_body_region_ablation.py
    Report: runs/pose-models/p4_pose_region_ablation_20260429_170054/ablation_report.txt
    **Scope (not all 9 pain pairs):** the shipped ablation_report covers **five**
    pain-involved OvO heads — **Paining|Resting**, **Fighting|Paining**, **Warning|Paining**,
    **HuntingMind|Paining**, **Mating|Paining** — matching the script's
    `--audio10-preset paining_pairs` / five-model preset in the docstring.
    **Angry|Paining**, **Defence|Paining**, **Happy|Paining**, and **MotherCall|Paining**
    were **not** included in this run; do **not** claim full 9-pair ablation coverage.
    Protocol (abbrev.): human-validation holdout with CNN14 pseudo-labels; audio_conf > 0.65;
      ViTPose QC gates (mean_conf≥0.3, y_range<10); joint **zeroing** after
      normalize_pose for masks: **drop_head** joints **0;1;2**; **drop_front_leg_L**
      **5;6;7**; **drop_front_leg_R** **8;9;10**; hind legs **11–16**; combined paws /
      paws+head as listed in the report table.
    **Warning|Paining degeneracy:** for **Warning|Paining**, every ablation row shows the
      **same** macro_F1 (**0.4375**) and the delta table is all **zeros** — the underlying
      pairwise model behavior is **near-constant** (predicting the positive class for
      essentially all holdout samples at score > 0.5), so **joint masking does not change**
      the thresholded decision. This aligns with the stacking report's note that
      **Paining|Warning** has **mean P(pos)≈0.91** (degenerate base model). **Do not**
      interpret the Warning|Paining ablation block as showing meaningful body-region
      sensitivity.
    Example **deltas vs full** (macro F1) for non-degenerate pairs: **Paining_Resting** —
      drop_all_paws −0.083; drop_all_paws_and_head −0.204. **Fighting_Paining** —
      drop_head −0.058; drop_both_front_legs +0.038; drop_all_paws −0.157. **Mating_Paining**
      — drop_front_leg_L +0.044 vs full. Full tables and per-pair **n**, **AUC** in
      ablation_report.txt.
