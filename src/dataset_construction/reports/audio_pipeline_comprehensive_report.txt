2. PIPELINE FLOW (HIGH LEVEL)
--------------------------------------------------------------------------------

Diagram (conceptual DAG):

  Input video
       |
       +-- ffmpeg --> extracted_audio.wav (16 kHz mono)
       |
       +-- YAMNet --> P(cat) aggregated over time frames
                      |
                      +-- P(cat) >= threshold --> AUDIO BRANCH
                      |         |
                      |         +-- AudioSep (text query e.g. "cat sounds")
                      |         |         --> separated_audio.wav (written)
                      |         +-- CatEmotionModel (10-class softmax)
                      |
                      +-- P(cat) < threshold  --> VIDEO BRANCH (ViTPose + ST-GCN meta; out of scope here)

Sampling-rate note:
  - YAMNet path and ffmpeg extraction use 16 kHz for inference (pipeline).
  - AudioSep loads/resynthesizes internally at 32 kHz per vendored AudioSep/pipeline.py.
  - CatEmotionModel consumes waveforms at AudioConfig.sample_rate (16 kHz; 7 s target).

4. CONFIGURATIONS (DEFAULTS AND NOTABLE DIFFERENCES)
--------------------------------------------------------------------------------

Inference CLI defaults (ArgumentDefaultsHelpFormatter in pipeline.py):
  --cat-threshold 0.5  (routes to AUDIO branch when P(cat) >= 0.5)
  Default AudioSep YAML: AudioSep/config/audiosep_base.yaml
  Default AudioSep ckpt: AudioSep/checkpoint/audiosep_base_4M_steps.ckpt
  Default emotion ckpt helper text: models/audio_emotions/best_model_final.pth
                           (resolved like audio_branch.EMOTION_CKPT_CANDIDATES)

Inference audio_branch.py specifics:
  Text query passed to AudioSep: default string "cat sounds".
  Separation output filename in run dir: separated_audio.wav
  IDX_TO_CLASS (10-way): Angry, Defence, Fighting, Happy, HuntingMind, Mating,
    MotherCall, Paining, Resting, Warning (indices 0..9).

audio-pre-classifier config.py (evaluation / development defaults):
  DEFAULT_THRESHOLD 0.02 for binary predictions in evaluate_v2_data (not identical to inference 0.5).
  INCLUDE_ROARING_CATS false by default.

data_pipeline_v2 default YAML (scraping / chunk gating — PyTorch YamNet backend):
  audio.backend: yamnet
  cat_prob_threshold: 0.65
  yamnet_aggregate_cat_classes: sum
  yamnet_include_roaring_cats: false

youtube scraper YAML (tensorflow_hub YamNetGate):
  audio.yamnet_threshold: 0.30 (when use_yamnet true)
  cat_sound_classes: Cat, Meow, Purr, Hiss

CatEmotionModel AudioConfig (audio_classifier_utils/audio_config.py):
  sample_rate: 16000
  target_length: 7 * sample_rate  (seven seconds padded/trimmed)
  pretrained backbone checkpoint path default:
    audio_classifier_utils/pretrained_weights/Cnn14_16k_mAP=0.438.pth

6. DATASET / SCRAPER INTEGRATION
--------------------------------------------------------------------------------

For multi-host collection (data_pipeline_v2), tracked processing uses AudioClassifier
with YAMNet v3 backend for per-chunk "cat sound" gating aggregated against
cat_prob_threshold — see configs under src/scrapers/data_pipeline_v2/config/.

YouTube path may still use YamNetCatGate (TensorFlow Hub) with discrete class subset
rather than aggregated torch_audioset indices.

Design consistency: scraped candidates are gated on raw/chunk audio; bulk emotion
pseudo-labeling for manifests runs on SEPARATED files under src/dataset_construction/
separeted_audios/ via 04_audio_classification.py (distinct stage from downloader gate).

8. UPSTREAM AudioSep EVALUATION (VENDOR TREE)
--------------------------------------------------------------------------------

Under AudioSep/evaluation/*.py and AudioSep/benchmark.py the upstream project computes
classic source-separation diagnostics (SDR / SISDR, etc.) on public mixture datasets.
These benchmarks assess AudioSep acoustic separation fidelity — they do not measure
Cats-in-Pain CatEmotionModel agreement before vs after separation, nor pain routing.


--------------------------------------------------------------------------------
9. LIMITATIONS, GAPS, AND IMPLEMENTATION CAVEATS
--------------------------------------------------------------------------------

9.A  AudioSep-vs-raw "consistency" testing: notebooks vs runnable scripts
   There is **no** small standalone Python module under ``src/`` or ``audio/`` that
   reproducibly reruns mixture-vs-separated stress tests from the CLI.

   There **is** substantial exploratory/stress-style analysis (prediction agreement,
   KL, Fréchet distance, MMD, UMAP embeddings) comparing **paired** NAYA files in
   ``data/audio_cat-classification/raw/NAYA_DATA_AUG1X`` vs sibling paths under
   ``data/audio_cat-classification/processed/processed/`` (same stems, AudioSep-like
   pipeline output as used in that workflow), in:

     _archive/top_level_notebooks/checking_extraction_real_vs_distribution.ipynb

   That notebook computes ``real_preds`` vs ``proc_preds`` alignment, symmetric KL,
   and distribution drift (notebook output on one run cites e.g. ~94.09% prediction
   agreement, FD ratio ~1.19× baseline, MMD ratio ~4.03× baseline) and discusses
   per-class fragility (e.g. MotherCall vs Resting, Warning agreement). Narrative in
   the notebook sometimes refers generically to "U-Net"; the comparison is framed as
   raw vs separation-processed audio for the emotion model — treat as archival
   research notes, not a pinned regression test.
   **Tabulated stdout from that notebook’s committed run appears in §7.C** (2961 pairs,
   175 flips, per-class breakdown, FD/MMD block).

   See **Section 11** for every AudioSep-touching notebook/script path located.

   YAMNet-only stress-testing (non-cat roots / manifest): see
   audio/audio-pre-classifier/README.md and evaluate_v2_data.py — not AudioSep.

   Design-time pipeline consistency: CLI inference audio branch + Step 04 both run
   CatEmotionModel after separation with default AudioSep query "cat sounds" unless
   overridden in code.

9.B  separate_cat_sounds.py copy under dataset_construction
   File: src/dataset_construction/separeted_audios/separate_cat_sounds.py
   The module sets REPO_ROOT = parent of the separeted_audios folder (i.e.
   src/dataset_construction), not the repository root. Default AudioSep config paths
   like REPO_ROOT / "config/audiosep_base.yaml" would then not resolve to
   AudioSep/config/ at the real repo root unless the script was modified or run with
   adjusted paths. Prefer the maintained script under AudioSep/separeted_audios/
   for batch separation unless this copy is repaired.

9.C  Manifest merge after Step 04
   src/dataset_construction/README.md notes that merge of metadata_clean_03 into
   metadata_clean_04 after audio classification was not implemented at doc time;
   final_dataset still consumes metadata_clean_04 when that pipeline is complete.

10. HOW TO REPRODUCE (ORDERED COMMANDS FROM REPO DOCS)
--------------------------------------------------------------------------------

From repository root unless noted.

10.1  YAMNet pre-classifier environment
  pip install -r audio/audio-pre-classifier/requirements.txt

10.2  YAMNet evaluation (binary cat vs non-cat metrics)
  cd audio/audio-pre-classifier
  PYTHONPATH=. python src/evaluate_v2_data.py --help

10.3  Inference audio branch dependencies
  pip install -r src/inference/requirements-audiosep.txt

10.4  End-to-end inference (single video)
  python src/inference/pipeline.py --video path/to/clip.mp4
  Optional: --cat-threshold, --audiosep-config, --audiosep-ckpt, --emotion-ckpt
  Sliding windows: --split-window-sec N --split-step-sec M

10.5  Batch emotion labels on separated audio (Step 04)
  python audio/audio-emotion-classifier/inference/04_audio_classification.py
  (defaults as in audio-emotion-classifier README; dry-run and --limit supported)

10.6  Regenerate thesis audio figures (if manifest available)
  See src/dataset_construction/paper_figures/ and generate_plots.py usage in that package.

10.7  Index of related commands
  docs/script-index.md (inference row, audio emotion row, YAMNet evaluation row)

10.8  Archive AudioSep / raw-vs-processed analysis (Jupyter)
  Open from repo root (paths may need adjusting for your machine):
    _archive/top_level_notebooks/checking_extraction_real_vs_distribution.ipynb
